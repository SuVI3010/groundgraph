# GroundGraph

GroundGraph is a local-first airport operations recovery command center. It continuously replans a bounded historical O'Hare replay using communicating specialist agents, a local model, and FalkorDB as the shared operational graph, memory, and policy layer.

This repository is the event-period implementation for the 2026 FalkorDB GraphRAG Hackathon. Development began after the official opening time on October 15, 2026 (IST).

## Status

Active hackathon build. Setup, architecture, track evidence, data provenance, and the judge demo will be documented here as they stabilize.
